# negative25 手机版适配设计

## 背景与目标

当前项目已经包含部分响应式规则，但规则分散在页面和组件中，手机端仍可能出现导航挤压、图片网格留白、浮层遮挡、参数溢出以及后台操作不适合触屏的问题。本次工作只优化手机和平板窄屏体验，保持现有视觉风格、业务逻辑、路由和桌面端交互不变。

主要验证视口为 `390x844`、`430x932` 和 `768x1024`。适配结果应满足：页面没有横向滚动；主要按钮和输入控件可触摸；内容不会被底部导航、安全区或浮层遮挡；返回照片详情或图库时保持原有浏览上下文。

## 方案选择

采用“现有组件内的移动端专属布局规则”方案。每个页面继续复用桌面端组件和数据流，只在明确的断点下重排布局、收敛尺寸和调整交互容器。

- 追加全局规则只负责基础安全区、溢出和通用触控尺寸。
- 页面级规则负责首页、相册、用户主页、认证页和账户页的栅格与间距。
- 组件级规则负责顶部导航、视图切换器、照片查看器、照片参数面板和发现地图抽屉。
- 不建立第二套手机页面，避免桌面和手机逻辑分叉。

## 布局与交互设计

### 全局与导航

- 页面根容器使用 `100dvh`/`100svh` 兼容写法，保留现有 `overflow-x: hidden`。
- 手机端页面水平内边距统一为 `16px`，在地图全屏场景中取消页面边距。
- 顶部导航保持品牌、搜索和用户入口可见；分类导航允许横向滚动，但不会把页面宽度撑开。
- 底部 `ViewSelector` 固定在安全区上方，并给内容预留等高底部空间；地图页不让切换器遮挡地图操作控件。
- 可点击控件的实际触控区域不小于约 `40px`，不依赖 hover 状态完成关键操作。

### 图库、精选/最近/随机与影册

- 图库图片使用自适应两列为主，在更窄屏幕下保持图片比例和稳定的行高，不固定桌面列宽。
- 精选、最近、随机沿用当前排序和随机逻辑，只优化卡片宽度、间距和加载期间的占位，避免滚动时重新计算导致跳动。
- 影册堆叠卡片在手机端使用两列，标题和时间信息始终位于卡片可见区域；展开后的照片行允许在容器内自然换行，不产生右侧空白。
- 相册列表和相册详情在手机端改为单列，并保持封面、标题、时间和操作按钮的阅读顺序。

### 照片查看器与参数

- 查看器继续全屏覆盖，图片按可用高度缩放；标题、关闭和三点按钮避开顶部安全区。
- 详细参数面板保持轻量浮层，在手机端靠近触发按钮或底部展开，不居中遮住整张照片。
- 参数字段允许换行或省略长设备名称，评级星星和操作按钮不超出屏幕。
- 关闭查看器和浏览器返回继续复用现有 photo-return 上下文，保持图库滚动位置和筛选条件。

### 发现地图

- 地图保持全屏，使用 `100svh` 兜底并在支持时使用动态视口高度。
- 地点搜索结果、位置详情和圈选结果在手机端统一为底部抽屉，抽屉内部独立滚动，地图仍可拖动和缩放。
- 抽屉顶部保留可识别的拖拽/收起区域，按钮和照片卡片满足触控尺寸；展开和收起不会改变已选择的地区。
- 地图控制按钮避开底部抽屉和安全区，主题样式继续跟随全局主题变量。

### 认证、个人中心与后台

- 登录和注册表单改为单列，输入框和提交按钮占满可用宽度，错误信息在字段下方换行显示。
- 个人中心账户导航在手机端横向滚动，内容区单列显示，表单操作按钮可换行。
- 后台照片管理、导入、相册和设置页面隐藏不适合窄屏的表头列，将每行信息重排为缩略图、核心信息、状态和操作；筛选器单列堆叠。
- 批量选择、删除、复制状态和导入操作保留现有确认流程，操作栏在手机端固定或自然换行，不遮住列表内容。

## 数据流与错误处理

本次不改变 API、Pinia store 或路由数据流。所有移动端布局只消费现有响应式状态。媒体加载失败继续使用现有占位和错误状态；抽屉和查看器关闭时不清空筛选、地区和照片上下文。任何新增的尺寸计算都使用 CSS `min() / max() / clamp()`，在缺少安全区变量的浏览器中回退到固定间距。

## 验证计划

1. 启动本地开发服务器，使用 Playwright 截取三个目标视口。
2. 检查首页、发现地图、照片详情、相册、公开用户主页、登录注册、个人中心和后台照片管理。
3. 在手机视口验证无横向滚动、无内容遮挡、底部安全区可见、图片网格无异常留白。
4. 验证关键触控流程：首页切换精选/最近/随机、地区确认后刷新、打开和关闭照片、展开影册、地图打开地点详情、登录注册和后台批量操作。
5. 运行前端单测、类型检查、全量 E2E 和生产构建；发现问题后按组件边界修复并重新截屏确认。

## 非目标

- 不修改桌面端视觉风格和业务排序规则。
- 不更换地图供应商、对象存储、API 合约或认证模型。
- 本轮只做本地修改和验证，不自动部署服务器。
