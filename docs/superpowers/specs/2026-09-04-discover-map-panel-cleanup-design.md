# Discover Map Panel Cleanup

## Goal

简化发现页地图面板，移除不需要的服务提示和亚洲分组文案，并恢复面板内容的纵向滚动。

## Design

- 不再渲染地点服务不可用提示条；地点接口失败时仍保留已有照片位置数据，不用额外提示模块占用面板空间。
- 搜索框隐藏浏览器原生搜索清除控件，仅保留组件自定义清除按钮，保证视觉上只有一个叉号。
- 保留 `asia` 地理分类用于地图和搜索，但不在面板分组列表中展示“亚洲探索”，也不改变其他分组。
- 面板内部容器使用纵向 `overflow-y: auto`、横向隐藏，地点卡片轨道继续使用横向滚动。

## Verification

- 更新 Discover E2E 用例，覆盖提示条隐藏、清除按钮唯一、亚洲分组不显示和面板可纵向滚动。
- 运行 Web 类型检查、单元测试和 Discover E2E。
