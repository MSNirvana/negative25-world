# 照片批次折叠与批次全选设计

## 范围

在管理端照片页对现有导入批次分组增加折叠展示和批次级选择，不改接口、数据库或单张照片编辑逻辑。

## 交互

- 照片列表首次有数据时，仅当前列表中的第一个导入批次展开，其余批次折叠。
- 点击批次标题可切换该批次展开/折叠状态；各批次可独立展开，不采用强制单开手风琴。
- 每个批次标题提供“批次全选/取消全选”按钮。
- 批次全选只作用于该批次在当前地点和状态筛选后的照片。
- 再次点击批次全选按钮取消该批次当前可见照片的选择；其他批次和筛选外照片的选择保持不变。
- 批次内照片数量继续显示当前筛选结果数量；全局选择工具栏保持原有行为。

## 实现

- 使用批次 key 维护展开状态，批次分组变化时清理已不存在的 key，并在没有可见展开批次时展开第一组。
- 复用 `selectedIds`，通过批次照片 ID 集合判断全选状态并切换选择。
- 为折叠按钮、批次全选按钮增加可访问名称、展开状态和本地化文案。

## 验证

- 类型检查通过。
- 前端测试覆盖批次选择 ID 的全选、取消全选和筛选后范围。
- 前端测试与生产构建通过。
