# n25 全站中英切换设计

## 目标

为 n25.world 的公开页面和 Studio 管理后台增加中英切换。默认语言为简体中文；用户切换后立即更新当前页面，并在刷新和路由切换后保留选择。

## 范围

覆盖 Gallery、Discover、相册列表、相册详情、照片查看器、About、Studio 登录、Studio 概览、导入、照片、相册和设置页面。覆盖可见静态文案、加载/错误/空状态、表单标签、操作反馈、确认弹窗以及 ARIA 标签。

照片标题、描述、地点、相册名称等由用户或 API 返回的内容保持原文，不做自动翻译。API 返回的具体错误信息也保持原文；仅替换代码中的兜底错误文案。

## 方案

采用无第三方依赖的本地词典和共享 locale composable：

- `apps/web/src/i18n.ts` 暴露 `useLocale()`、`t()` 和 `Locale` 类型。
- 支持 `zh` 与 `en`；首次加载和非法存储值均回退 `zh`。
- 使用 `negative25.locale` 持久化语言；写入失败不影响运行时切换。
- 语言变化时同步设置 `document.documentElement.lang` 为 `zh-CN` 或 `en`。
- 词典值支持简单命名插值，用于数量、名称和状态等已有动态文本。

## 组件集成

新增 `LanguageSwitcher.vue`，使用紧凑的 `中 / EN` 分段控件，并提供 `aria-label`、当前选中状态和键盘焦点样式。将控件放入：

- `AppHeader.vue`：公开页面常规头部。
- `PhotoViewer.vue`：照片页没有常规头部时的顶部操作区。
- `AdminLayout.vue`：Studio 页面。
- `AdminLoginView.vue`：未进入 Studio 外壳的登录页。

各页面通过 `t('...')` 读取静态词典。共享组件（CategoryNav、ViewSelector、PublicFooter、PhotoMeta、ErrorState、LoadingState、ImportDropzone）也接入同一词典，避免局部语言不一致。

## 状态与数据流

1. 应用启动时创建共享 locale 状态，并从 `negative25.locale` 读取有效值。
2. `LanguageSwitcher` 调用 `setLocale`。
3. `setLocale` 更新响应式状态、持久化值和 HTML `lang` 属性。
4. 所有使用 `t()` 的模板随响应式 locale 自动重新渲染；路由、图库数据和 API 请求不变。

## 失败处理

- `localStorage` 不可用时只跳过持久化，仍允许内存切换。
- 中文词典缺键时回退英文词典；英文也缺键时返回键名并在开发环境发出警告，避免出现空白 UI。
- 动态内容中的数字和名称继续由现有组件渲染，不因语言切换丢失。

## 测试与验收

- 单测覆盖默认中文、存储恢复、非法值回退、切换后的 HTML `lang` 和插值。
- 组件/E2E 检查公开页、照片页、Studio 登录和 Studio 内页均能切换，且切换后静态文案立即更新。
- 运行 web lint、typecheck、unit tests 和 production build。
- 在 1280px 和 390px 视口检查控件位置、长中文文案换行、无水平溢出和焦点可见性。

## 不在范围内

- 不翻译 API 中存储的用户内容。
- 不改变 API 合约、路由、图库排序、权限或导入行为。
- 不增加第三方国际化运行时依赖。
