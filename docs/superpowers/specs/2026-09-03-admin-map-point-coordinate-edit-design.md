# 后台手动地点与地图点选坐标编辑设计

## 背景

高德地图的海外 POI 搜索覆盖不稳定。照片管理需要支持用户手动输入地点名称，再通过地图点选或经纬度输入完成定位，尤其用于海外地点。现有 `AdminLocationPicker` 已负责高德地图加载、国内地点搜索、标记显示和坐标转换，但尚未支持地图点击定位和经纬度编辑。

## 目标

- 保留用户手动输入的地点名称，不用高德搜索结果或地图点选覆盖名称。
- 点击地图任意位置后自动写入坐标并移动标记。
- 展示当前纬度、经度，允许用户直接修改。
- 修改经纬度后同步移动地图标记。
- 国内点选继续正确处理高德 GCJ-02 与应用保存的 WGS84 转换；海外坐标按 WGS84 原值保存。
- 不接入新的海外搜索服务，不改变公开地图、位置筛选和照片数据结构。

## 交互设计

### 地点名称与搜索

现有搜索输入框继续作为地点名称输入，并保留高德搜索按钮。输入框标签和提示文案明确它既可手动填写、也可用于搜索。用户手动输入时，组件通过 `update:name` 将文本实时同步到父级照片草稿，确保海外名称可以保存。高德搜索结果的选择行为保持现状，用于国内地点快速定位；地图点选行为不读取搜索结果文本。

### 地图点选

- 用户在地图上点击一个位置时，使用点击事件的经纬度放置或移动标记。
- 点击位置转换为应用保存格式后，更新父级草稿的 `latitude` 与 `longitude`。
- 地点名称、显示地址保持用户当前填写内容，不执行反向地理编码，也不补写高德返回的地点名称。地图点选只更新坐标；若用户刚输入了新的名称，该名称已经通过 `update:name` 同步到父级。
- 地图点选不生成省份/地区前缀。若编辑已有地点，清除旧的 `displayRegion` 并关闭地区前缀开关，避免旧地区信息与新坐标不一致。
- 拖动地图只改变视口，不自动改变已保存坐标；只有明确点击地图才选点。

### 经纬度编辑

- 地图下方显示两个十进制度数输入框：纬度和经度，展示最多 6 位小数。
- 点选地图或选择搜索结果后，输入框立即显示最新坐标。
- 修改输入框并失焦或按 Enter 后，若两个值均为合法数字，地图标记移动到新位置，地图视口以该点为中心。
- 输入过程中允许暂时为空或输入中间态，不在每个按键时强制改动地图；提交保存前统一校验。
- 纬度合法范围为 `-90` 至 `90`，经度合法范围为 `-180` 至 `180`；必须同时填写两个值。
- 输入非法时显示现有定位坐标错误提示，不移动标记，也不提交非法值。

### 清除定位

继续使用现有“清除位置”操作，同时清除标记、输入框中的地点名称、显示地址、地区前缀和两个坐标值。

## 数据流与组件边界

- `AdminLocationPicker.vue` 增加地图点击监听、坐标输入状态、`update:name` 和统一的坐标更新事件。地图点击与经纬度编辑都通过坐标更新事件通知父级；组件内部负责 AMap 坐标与 WGS84 的转换、标记和视口同步。
- `AdminPhotosView.vue` 监听名称同步和坐标更新事件。坐标更新只修改草稿坐标，不改变地点名称和显示地址；地区字段按上述规则清理。
- 保存请求仍使用既有 `location: { name, latitude, longitude, displayAddress, displayRegion, displayRegionEnabled }` 结构，不新增 API 字段或数据库迁移。
- 保存前沿用坐标范围校验，并补充地点名称与坐标组合的清晰错误提示，避免产生没有名称的定位记录。
- 海外坐标经过现有 `toAMapCoordinates`/`fromAMapCoordinates` 时保持 WGS84；中国大陆坐标继续执行 GCJ-02 转换。

## 错误处理

- 地图未加载或高德 Key 不可用时，保留现有错误状态；经纬度输入仍可编辑，直到保存时校验。
- 只有一个坐标输入有效时，不更新标记并提示需同时填写纬度和经度。
- 超出范围、非数字或空值不会覆盖最后一个有效标记位置。
- 地图点击事件缺少有效坐标时忽略，不影响当前草稿。

## 测试与验证

- 为坐标解析、范围校验和输入中间态补充纯函数单元测试。
- 运行 Web 类型检查、现有 Web 测试和生产构建。
- 浏览器验证：
  - 输入“新加坡”，点击海外地图后名称仍为“新加坡”，坐标自动出现；
  - 手动修改坐标，标记移动到新位置；
  - 输入无效坐标时标记和最后有效值保持不变；
  - 搜索国内地点的既有流程仍能更新位置；
  - 清除定位会清空名称、显示字段、坐标和标记。

## 非目标

- 不实现海外 POI 搜索或自动反向地址识别。
- 不更换高德地图供应商，不改公开端地图展示逻辑。
- 不将地图拖动后的中心点默认为照片定位点。
