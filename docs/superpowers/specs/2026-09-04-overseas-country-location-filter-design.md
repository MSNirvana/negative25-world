# 海外国家/地区筛选归并设计

## 背景

图库顶部的“地区”筛选器对中国照片按省级地区归类，但海外照片目前按完整地点名称生成选项。照片显示地址通常包含国家前缀和具体景点，例如“新加坡·金沙赌场”“新加坡·鱼尾狮”，因此同一个国家会被拆成多个筛选项。

## 目标

- 将海外照片按国家/地区合并为一个筛选项。
- “新加坡·金沙赌场”“新加坡·鱼尾狮”等统一归入“新加坡”。
- 选择国家/地区后显示该国家的全部照片。
- 保留照片卡片和详情中的具体地点名称，不改写照片数据。
- 中国 34 个省级地区的现有归类和筛选行为保持不变。
- 无法可靠识别国家的海外地点继续按原地点名称显示，不强行猜测。

## 归类规则

### 中国优先

继续先使用现有 `CHINA_REGION_DEFINITIONS` 和照片的地点名称、原始地点名称、地区元数据及地点 ID 识别中国省级地区。命中中国地区的照片不进入海外归类。

### 海外国家识别优先级

对未命中中国地区且地点有效的照片，按以下顺序确定国家/地区分组：

1. 使用 `locationRegion`（来源于 `metadata.displayRegion`）。这是管理员明确保存的地区字段，优先级最高。
2. 从格式化显示地点 `location` 的国家前缀或后缀识别：支持中点分隔的“国家·景点”、逗号分隔的“景点, Country”及常见空格/斜杠分隔形式。
3. 从原始地点名称 `locationName` 中识别已知国家别名。
4. 如果仍无法识别，使用当前完整地点名称作为独立海外选项，保持现有行为。

归类只使用本地纯函数和静态别名，不发起反向地理编码或新增地图服务请求。

## 国家别名与选项模型

- 增加可维护的海外国家别名表，至少覆盖当前数据中的新加坡及其英文名称 `新加坡`、`Singapore`，并为常见国家保留中文/英文别名扩展点。
- 每个海外选项使用稳定的国家 ID（例如 `singapore`），显示名称优先使用标准中文国家名称；英文界面使用对应英文名称。
- 选项的 `aliases` 保存该国家可匹配的标准名、别名和历史地点标签，供筛选匹配使用。
- 同一国家的照片数量按照片 ID 去重后统计，避免完整地区目录分页重复造成数量膨胀。

## 筛选行为

- `buildLocationOptions` 继续返回 34 个中国省级选项和已有照片对应的海外国家/地区选项。
- `photoMatchesLocation` 对中国选项沿用原规则；对海外选项按国家分组键匹配，不再要求完整地点标签完全相同。
- 用户选择“新加坡”时，所有识别为新加坡的照片均进入 `mode=location` 请求；API 的 location 查询也使用同一国家归类函数，按稳定国家 ID 返回完整结果。
- 搜索框同时匹配中文国家名、英文国家名和选项别名。
- 具体景点不会作为地区选项显示，但仍保留在照片的 `location`、详情和搜索文本中。

## 兼容与边界

- 已保存的照片地点、显示地址、地区字段和坐标不做迁移或批量修改。
- 显示地址未开启地区前缀时，仍可从原始地点名称或 `locationRegion` 归类；关闭前缀不会导致照片丢失。
- `locationRegion` 为空且地点名称只包含景点、不含国家信息时，不根据坐标猜测国家，继续按完整地点名称展示。
- 国家别名匹配使用规范化大小写、空白和常用分隔符，避免“Singapore”“singapore”被拆分。
- 归类冲突时优先使用明确的 `locationRegion`，其次使用可识别的地点文本，最后才回退完整地点。

## 组件与文件边界

- 在 `packages/contracts/src/location-options.ts` 增加可供前后端共用的海外国家别名、国家归类和规范化函数。
- 在 `apps/web/src/lib/location-options.ts` 增加海外国家选项构造和照片匹配逻辑，并调用 contracts 中的共用归类函数。
- `LocationPicker.vue` 只继续消费 `LocationOption`，不增加新的 UI 交互；选项文本和数量自然反映合并结果。
- 在 `apps/api/src/modules/workspaces/workspace.routes.ts` 扩展 location 查询，使稳定海外国家 ID与前端选项保持一致。
- `gallery.ts`、数据库结构和照片保存流程不修改。
- 为海外归类、同国多景点合并、中文/英文别名、未知地点回退和筛选匹配增加纯函数测试。

## 验证

- 单元测试确认 6 个新加坡景点只生成一个“新加坡”选项，并且数量为全部照片数。
- 单元测试确认选择稳定 ID 能匹配该国家的不同地点写法。
- 单元测试确认中国省份归类结果不变，未知海外地点仍保持独立选项。
- 运行 Web 类型检查、全部 Web 测试、生产构建和 `git diff --check`。
- 浏览器验证地区选择器显示一个“新加坡”选项，选择后照片数量和列表正确，照片上的具体景点名称仍保持原样。

## 非目标

- 不修改照片历史数据或地点名称。
- 不接入高德反向地理编码、Google Places、Mapbox 或其他海外地图服务。
- 不提供景点级的地区筛选；景点级搜索仍由现有地点/图库搜索承担。
