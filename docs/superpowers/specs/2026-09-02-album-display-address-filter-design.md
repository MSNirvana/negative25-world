# 新建相册显示地址筛选设计

## 范围

在管理端新建/编辑相册的照片选择区域增加“显示地址”文本筛选。筛选针对当前已经加载到编辑器的照片执行，不新增接口、数据库字段或服务端查询。

## 交互

- 在“照片 / 已选择”区域下方提供一个文本输入框。
- 输入内容后实时按包含关系匹配照片的显示地址，忽略大小写。
- 显示地址读取照片 `metadata.displayAddress`；没有显示地址的照片不匹配非空查询。
- 清空输入框后恢复显示全部照片。
- 筛选只影响可见列表，不改变已选择的照片；已选择计数和封面选择逻辑保持现状。
- 筛选无结果时显示现有空状态文案，不影响保存相册。

## 实现

- 在 `AdminAlbumsView.vue` 增加筛选输入状态和计算属性。
- 将照片选择列表的遍历源改为筛选后的照片列表。
- 增加对应中英文国际化文案和必要的无结果文案。
- 保持现有桌面双列、移动端单列布局，并复用现有表单样式。

## 验证

- 类型检查通过。
- 前端单元测试通过；至少覆盖显示地址包含匹配、大小写不敏感、空查询恢复全部照片。
- 生产构建通过。
