# negative25 产品导览

本文档对应 README 中的真实界面截图和产品导览视频。素材采集日期：2026-09-07。截图来自公开演示环境，未复制线上原始照片到仓库。

## 浏览路径

1. 首页进入“精选”，查看按评分整理的作品；
2. 切换“最近”或“随机浏览”，观察不同的浏览逻辑；
3. 打开“发现”，使用世界地图和聚合点进入地点照片；
4. 打开“影册”，按封面和拍摄时间进入一个相册；
5. 在“个人中心”登录后进入导入和照片管理；
6. 导入照片后由 Worker 读取 EXIF、生成预览并写回照片档案。
