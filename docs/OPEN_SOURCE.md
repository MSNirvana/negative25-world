# negative25 开源说明

negative25 以 MIT License 发布，目标是让摄影师、个人工作室和小团队可以自己托管照片档案，而不是依赖单一平台的封闭数据结构。

## 数据边界

软件代码、文档和测试按 MIT License 发布。线上演示中的照片、Logo、地图服务凭据、服务器配置和用户账号不属于开源代码的一部分，也不会随仓库发布。

## 公开性模型

- 未登录访客看到管理员审核后的默认公开照片；
- 用户可以维护个人资料、影册和照片公开状态；
- 搜索用户后只展示该用户已经公开的内容；
- 原始上传文件默认私有，公开页面使用受控预览变体；
- 个人中心、导入、删除和审核操作需要登录权限。

## 发布前检查

    rg -n --hidden --glob '!.git' '(github_pat_|AKIA|MINIO_ROOT_PASSWORD|JWT_SECRET=|VITE_AMAP_KEY=|S3_SECRET)' .

命令没有输出不代表完成了安全审计，但可以拦截最常见的密钥误提交。生产密钥应由服务器 Secret Manager 注入，而不是写入 Compose 文件或 README。
