# negative25 宣传素材

## 一句话介绍

negative25 是一个可自托管的摄影档案馆：自动读取 EXIF，把作品、拍摄参数、地点地图和公开影册整理成一个多用户空间。

## GitHub 项目简介

建议仓库简介：

> An open-source photography archive with EXIF-aware uploads, public photo journals, albums, location discovery, maps, and responsive multi-user galleries.

建议 Topics：

photography · photo-gallery · exif · vue3 · fastify · typescript · minio · cloudflare-r2 · pwa · photo-management

## 宣传标题

- 把照片从“文件”整理成真正的摄影档案
- 你的照片不只要被看见，还要记住在哪里、怎么拍的
- 一套可以自己托管的多用户摄影影册

## 社区分享文案

negative25 是一个面向摄影师的开源摄影档案馆。它支持批量导入、EXIF 自动读取、焦距/光圈/快门/ISO、海拔和经纬度、世界地图发现、七星评级、影册、多用户公开主页，以及 MinIO 到 Cloudflare R2 的对象存储迁移路径。你可以自己部署，也可以从最小的本地 Docker 环境开始。
